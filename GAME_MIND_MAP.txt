# 6. COMBAT MECHANICS
# ═══════════════════════════════════════════════════════════════
#
#   ┌───────────────────────────────────────────┐
#   │          TURN STRUCTURE                   │
#   │                                           │
#   │   Player gets 2 actions ──┐               │
#   │                           │               │
#   │   Each action can be:     │               │
#   │   • Attack (1 action)     │               │
#   │   • Drink beer (1 action) │               │
#   │   • Eat food (1 action)   │               │
#   │   • Flee (1 action)       │               │
#   │                           │               │
#   │   After 2 actions ────────▼               │
#   │   Enemy attacks once                      │
#   │   Buffs tick down                         │
#   │   Next turn begins                        │
#   └───────────────────────────────────────────┘
#
#   DAMAGE FORMULA:
#     effective = max(1, ATK − target DEF)
#     crit? = random < critChance
#     damage = max(1, round(effective × (crit ? 1.5 : 1)))
#
#   FLEE:
#     35% success — skip round, return to explore
#     65% fail — lose all actions, enemy attacks immediately
#     Boss: cannot flee
#
#   LAGER SPEED BUFF:
#     Grants 2 attacks per Attack action for N turns
#     "Sahti speed strike: {dmg}" on the bonus hit
#
#   REST (explore only):
#     Heals 25% of max HP
