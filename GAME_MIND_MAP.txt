# 7. COMBAT MECHANICS
# ═══════════════════════════════════════════════════════════════
#
#   ┌───────────────────────────────────────────┐
#   │          TURN STRUCTURE                   │
#   │                                           │
#   │   Player gets 3 actions ──┐               │
#   │   (4 with Cornered Rat    │               │
#   │    relic when HP < 30%)   │               │
#   │                           │               │
#   │   Each action can be:     │               │
#   │   • Attack (1 action)     │               │
#   │   • Block  (1 action)     │               │
#   │   • Drink beer (1 action) │               │
#   │   • Eat food (1 action)   │               │
#   │   • Flee (ends turn)      │               │
#   │                           │               │
#   │   After all actions ──────▼               │
#   │   Enemy gets 2 strikes                    │
#   │   (or 1 strike + block at 30% chance)     │
#   │   Buffs tick down                         │
#   │   Next turn begins                        │
#   └───────────────────────────────────────────┘
#
#   DAMAGE FORMULA:
#     effective = max(1, ATK − target DEF)
#     crit? = random < critChance
#     damage = max(1, round(effective × (crit ? 1.5 : 1)))
#
#   BLOCK:
#     Player: isBlocking += DEF. Resets at start of player turn.
#     Enemy: 30% chance to block instead of second strike.
#     Auto-block relic: +6 block if player didn't block manually.
#
#   FLEE:
#     35% success — skip round, return to explore
#     65% fail — lose all actions, enemy turn begins
#     Boss: cannot flee
#
#   LAGER SPEED BUFF:
#     Grants 2 attacks per Attack action for N turns
#
#   REST (route node):
#     Heals 40% of max HP
